Ya llevo varias semanas construyendo este blog de autos con Astro, y aprendí bastante:

- **Componentes**: el encabezado, el menú y el pie de página se escriben una sola vez y se reutilizan en todas las páginas.
- **Layouts**: cada entrada del blog usa el mismo diseño, así solo tengo que escribir el contenido.
- **Frontmatter**: el título, la fecha y el autor se escriben arriba del archivo Markdown y el layout los muestra solo.

Lo siguiente es seguir agregando reseñas de autos deportivos.
